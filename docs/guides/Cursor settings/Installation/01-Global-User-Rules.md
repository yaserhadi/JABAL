# 01 — Global User Rules

**To:** All Development Team Members  
**Purpose:** Install 7 organizational governance rules via Cursor Settings UI

## What You're Installing

1. CAB governance
2. Agent investigation & Git safety
3. Global agent safety & integrity
4. Audit, risk, and compliance
5. Data protection and PII
6. Production environment safety
7. Git change management & branching

## Installation

1. Open Cursor → Settings (Ctrl+,)
2. Search "Rules for AI"
3. Click "Add Rule" and paste each of the 7 rules
