# Cursor Settings Distribution Pack

Copyable KSS files for colleagues. Install in order below.

## Installation Order

1. **Global User Rules** — Cursor Settings UI (7 rules)
2. **File-based rules** — Copy to `~/.cursor/rules/`
3. **Commands** — Copy to `~/.cursor/commands/`
4. **Agents** — Copy to `~/.cursor/agents/`
5. **Skills** — Copy to `~/.cursor/skills/` and `~/.cursor/skills-cursor/`
