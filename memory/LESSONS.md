# Lessons Learned

## Purpose
This file tracks mistakes, risks, and patterns that can recur. Use this to add guardrails and prevent repeating errors.

## Format
Each lesson should include:
- **Date**: When the lesson was learned
- **Context**: What happened
- **Root Cause**: Why it happened
- **Lesson**: What to avoid or do differently
- **Guardrail**: How to prevent recurrence
